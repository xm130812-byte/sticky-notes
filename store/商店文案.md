## 名称 Name

```
便签 · Sticky Notes
```

## 简述 Summary（≤132 字符）

```
像 Windows 便签一样随手记录：侧边栏、网页浮窗、全屏日记本，一键复制并插入网页。
```

## 详细说明 Description

```
便签 · Sticky Notes 是一个纯本地、零打扰的随手记事工具。想到什么，按一下快捷键就能记下来；需要的时候，它就在手边。

【三种形态，各用各的场景】
· 侧边栏：常驻浏览器右侧，浏览网页时随时翻看，不遮挡内容。
· 网页浮窗：浮在当前页面右上角，可以拖动、缩放、收起，边看资料边记。
· 全屏日记本：在新标签页里按日期展开全部记录，像翻日记一样回顾。

【主要功能】
· 记录自动保存，不需要点「保存」按钮
· 搜索便签，一键复制全文
· 选中网页上的文字，右键即可存成便签
· 一键把便签内容插入网页的输入框、文本框或编辑器
· 六种颜色标记，置顶重要内容
· 删除后可撤销，支持导入 / 导出备份
· 跟随系统深浅色，支持打印
· 全屏日记本内可直接编辑、删除，按创建日期自动分组

【快捷键】
· Ctrl+Shift+Y（Mac：Command+Shift+Y）打开侧边栏
· Alt+Shift+S 显示 / 隐藏网页浮窗
· Alt+Shift+N 新建一条便签

【隐私】
所有便签只保存在你自己的电脑上（chrome.storage.local）。扩展不联网、不上传、不收集任何数据，没有分析统计，没有广告。

【适合谁】
需要随时记下地址、会议要点、代码片段、临时灵感的人。
```

## English version（商店支持多语言时用）

### Summary

```
Sticky notes like the Windows app: side panel, floating panel and a full-page journal. Copy and insert into any page.
```

### Description

```
Sticky Notes is a local-only, distraction-free note tool. Press a shortcut, write it down; it is always within reach when you need it.

THREE FORMS FOR DIFFERENT MOMENTS
· Side panel: docked on the right, always visible while you browse.
· Floating panel: sits on top of the current page. Drag it, resize it, collapse it.
· Journal: all your notes laid out by date on a single full-page tab, grouped by the day they were created.

FEATURES
· Auto-save as you type
· Search, copy the whole note in one click
· Save selected text as a note from the right-click menu
· Insert a note straight into an input, textarea or contenteditable
· Six colors, pin important notes
· Undo delete, export / import backups
· Light and dark, print-friendly
· Edit and delete entries directly in the journal

SHORTCUTS
· Ctrl+Shift+Y (Mac: Command+Shift+Y) open the side panel
· Alt+Shift+S show / hide the floating panel
· Alt+Shift+N new note

PRIVACY
Everything stays on your computer in chrome.storage.local. No network requests, no uploads, no analytics, no ads.

SINGLE PURPOSE
A sticky-note extension that lets users quickly record, review and copy plain-text notes in the current browser.
```
